# AsyncDjango

Асинхронный веб-сервис на Python

## Описание

Этот сервис выполняет асинхронный расчет цены для LogisticTruck в фоновом режиме.

## Установка и запуск

1. Активируйте виртуальное окружение:
```bash
source ../async_service_env/bin/activate
```

2. Убедитесь, что установлены зависимости:
```bash
pip install Django==4.2.4 djangorestframework requests
```

3. Примените миграции (если нужно):
```bash
python manage.py migrate
```

4. Запустите сервер:
```bash
python manage.py runserver 0.0.0.0:8001
```

Сервис будет доступен на `http://localhost:8001`

## API

### POST `/` - Запуск расчета цены

Принимает POST запрос с полями `pk` (ID LogisticTruck) и `count_logistics` (количество километров) и запускает асинхронный расчет цены на основе километров.

**Пример запроса:**
```bash
curl -X POST http://localhost:8001/ \
  -H "Content-Type: application/json" \
  -d '{"pk": 1, "count_logistics": 100}'
```

**Ответ:**
```json
{
  "status": "calculation_started",
  "logistic_truck_id": 1,
  "count_logistics": 100
}
```

## Формула расчета цены

Цена рассчитывается по формуле:
```
цена = количество_км × базовая_цена_за_км × коэффициент
```

Где:
- `количество_км` - передается в запросе (`count_logistics`)
- `базовая_цена_за_км` - случайное значение от 50 до 150 рублей
- `коэффициент` - случайный множитель от 0.8 до 1.2
- Минимальная цена: 100 рублей

**Пример:**
- Количество км: 100
- Базовая цена: 80 руб/км
- Коэффициент: 1.1
- **Итоговая цена:** 100 × 80 × 1.1 = 8,800 рублей

## Как это работает

1. Django сервис получает POST запрос с ID LogisticTruck
2. Запускает долгую задачу (5-10 секунд) в фоновом режиме через ThreadPoolExecutor
3. Сразу возвращает ответ 200 OK
4. После завершения расчета отправляет PUT запрос на Go сервер с результатом
5. Go сервер обновляет цену в базе данных

## Конфигурация

- **CALLBACK_URL**: URL Go сервера для отправки результатов (по умолчанию: `http://localhost:8080/api/logistic-truck/`)
- **AUTH_TOKEN**: Токен для псевдо-авторизации (по умолчанию: `secret123`)

Эти значения можно изменить в файле `app/views.py`.
