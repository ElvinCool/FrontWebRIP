# Руководство по тестированию через Insomnia

## Подготовка

### 1. Импорт коллекции

1. Откройте Insomnia
2. Нажмите `Create` → `Import` → `From File`
3. Выберите файл `Insomnia_Collection.json`
4. Коллекция будет импортирована с группами запросов

### 2. Настройка переменных окружения

В Insomnia настройте переменные окружения:

- `base_url`: `http://localhost:8080` (Go сервер)
- `django_url`: `http://localhost:8001` (Django сервис)
- `truck_id`: `1` (ID грузовика для тестирования)
- `logistic_id`: `1` (ID заявки - будет обновляться по ходу тестирования)
- `logistic_truck_id`: `1` (ID LogisticTruck - будет обновляться по ходу тестирования)

## Последовательность тестирования

### Шаг 1: Авторизация

1. **1. Регистрация пользователя**
   - Запустите запрос
   - Если пользователь уже существует, получите ошибку (это нормально)
   - Можно пропустить, если пользователь уже зарегистрирован

2. **2. Вход пользователя**
   - Запустите запрос
   - ✅ Должен вернуть `200 OK` с данными пользователя
   - Cookie сессии сохранится автоматически

3. **3. Получить текущего пользователя**
   - Проверка, что авторизация работает
   - ✅ Должен вернуть данные пользователя

### Шаг 2: Создание заявки

4. **4. Получить список грузовиков**
   - Получите список доступных грузовиков
   - Запомните ID одного или нескольких грузовиков
   - Обновите переменную `truck_id` в окружении

5. **5. Получить черновик заявки**
   - Создаст или вернет черновик заявки
   - ✅ Должен вернуть `{"id": X, "service_count": 0}`
   - **ВАЖНО**: Запомните `id` заявки и обновите переменную `logistic_id`

6. **6. Добавить грузовик в черновик**
   - Замените `{{ _.truck_id }}` на реальный ID грузовика (или используйте переменную)
   - Запустите запрос несколько раз с разными грузовиками
   - ✅ Должен вернуть `{"status": "truck added to draft logistic", "truck": X}`

7. **7. Сохранить заявку**
   - Замените `{{ _.logistic_id }}` на ID заявки из шага 5
   - ✅ Должен вернуть `{"status": "сформирован"}`

### Шаг 3: Тестирование асинхронного сервиса

⚠️ **ВАЖНО**: Перед этим шагом убедитесь, что Django сервис запущен:
```bash
cd async_service_dir
source ../async_service_env/bin/activate
python manage.py runserver 0.0.0.0:8001
```

8. **8. Получить список заявок**
   - Проверьте, что заявка в статусе "сформирован"
   - Найдите ID заявки и обновите переменную `logistic_id`
   - Проверьте поле `calculated_count` - должно быть `0` (цены еще не рассчитаны)

9. **9. Получить заявку по ID**
   - Получите детальную информацию о заявке
   - Проверьте `logistic_trucks` - все цены должны быть `0`
   - Запомните ID первого `logistic_trucks[0].id` и обновите `logistic_truck_id`

10. **10. Завершить заявку (МОДЕРАТОР)** ⚡
    - ⚠️ **ВАЖНО**: Нужна авторизация как модератор!
    - Замените `{{ _.logistic_id }}` на ID заявки
    - Запустите запрос
    - ✅ Сразу вернется `{"status": "завершен"}`
    - 📊 В логах Django сервиса появятся запросы на расчет
    - ⏱️ Подождите 5-10 секунд

11. **9. Получить заявку по ID** (повторно)
    - Запустите запрос снова через 10 секунд
    - ✅ Проверьте `logistic_trucks` - цены должны быть обновлены (от 100 до 1000)
    - ✅ Проверьте `calculated_count` - должно быть равно количеству LogisticTrucks

### Шаг 4: Прямое тестирование Django сервиса

12. **11. Django: Запустить расчет цены (прямой тест)**
    - Замените `{{ _.logistic_truck_id }}` на ID LogisticTruck
    - ✅ Должен вернуть `{"status": "calculation_started", "logistic_truck_id": X}`
    - ⏱️ Подождите 5-10 секунд
    - Проверьте логи Django сервиса

13. **9. Получить заявку по ID** (повторно)
    - Проверьте, что цена обновилась

### Шаг 5: Тестирование авторизации

14. **12. Обновить цену LogisticTruck (с токеном)**
    - Замените `{{ _.logistic_truck_id }}` на ID LogisticTruck
    - URL: `PUT http://localhost:8080/api/logistic-trucks/:id/price`
    - ✅ Должен вернуть `{"status": "price_updated", "id": X, "price": 500.0}`

15. **13. Обновить цену БЕЗ токена (должна быть ошибка)**
    - ✅ Должен вернуть `401 Unauthorized` с сообщением `"invalid token"`

## Проверка результатов

### Что должно работать:

1. ✅ При завершении заявки сразу возвращается ответ (не ждет 5-10 секунд)
2. ✅ Через 5-10 секунд цены LogisticTrucks обновляются в БД
3. ✅ Поле `calculated_count` увеличивается после расчета цен
4. ✅ Django сервис отправляет результаты обратно на Go сервер
5. ✅ Авторизация по токену работает (без токена - ошибка)

### Логи для проверки:

**Go сервер:**
- При завершении заявки должны появиться логи о вызове Django сервиса
- При получении результатов должны появиться логи об обновлении цен

**Django сервис:**
- Должны появиться логи: `Calculation completed for LogisticTruck ID X, price: Y`
- Должны появиться логи: `Sent price update to Go server: 200`

## Возможные проблемы

### Django сервис не отвечает
- Проверьте, что сервис запущен на порту 8001
- Проверьте логи Django сервиса

### Цены не обновляются
- Проверьте логи Django сервиса на ошибки
- Проверьте, что Go сервер доступен на порту 8080
- Проверьте токен авторизации (`secret123`)

### Ошибка авторизации при завершении заявки
- Убедитесь, что вы авторизованы как модератор
- Проверьте cookie сессии

### Переменные не подставляются
- В Insomnia используйте `{{ _.variable_name }}` для подстановки переменных
- Проверьте, что переменные настроены в окружении

## Полезные советы

1. **Используйте переменные окружения** для быстрой смены ID
2. **Сохраняйте cookie** - Insomnia делает это автоматически
3. **Следите за логами** обоих серверов одновременно
4. **Используйте повторный запрос** для проверки обновленных данных
