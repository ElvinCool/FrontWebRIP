# Расчет цены на основе километров

## Как это работает

### 1. Пользователь указывает количество километров

При создании или обновлении LogisticTruck указывается поле `count_logistics` - это количество километров для перевозки.

### 2. При завершении заявки запускается расчет

Когда модератор завершает заявку, для каждого LogisticTruck:
- Go сервер отправляет в Django сервис:
  - `pk` - ID LogisticTruck
  - `count_logistics` - количество километров

### 3. Django сервис рассчитывает цену

**Формула расчета:**
```
цена = количество_км × базовая_цена_за_км × коэффициент
```

**Параметры:**
- `количество_км` - берется из `count_logistics`
- `базовая_цена_за_км` - случайное значение от 50 до 150 рублей (для разнообразия)
- `коэффициент` - случайный множитель от 0.8 до 1.2 (для учета различных факторов)
- `минимальная_цена` - 100 рублей (если расчет дал слишком маленькую цену)

### 4. Результат сохраняется в БД

После расчета (через 5-10 секунд) цена обновляется в поле `price` LogisticTruck.

## Примеры расчета

### Пример 1: 100 километров
- Количество км: 100
- Базовая цена: 80 руб/км
- Коэффициент: 1.1
- **Итоговая цена:** 100 × 80 × 1.1 = **8,800 рублей**

### Пример 2: 50 километров
- Количество км: 50
- Базовая цена: 120 руб/км
- Коэффициент: 0.9
- Расчет: 50 × 120 × 0.9 = 5,400 рублей
- Но минимальная цена 100 рублей, поэтому: **5,400 рублей** ✅

### Пример 3: 1 километр
- Количество км: 1
- Базовая цена: 60 руб/км
- Коэффициент: 1.0
- Расчет: 1 × 60 × 1.0 = 60 рублей
- Но минимальная цена 100 рублей, поэтому: **100 рублей** ✅

## Где указывать километры?

### При создании LogisticTruck:
По умолчанию `count_logistics = 1`, но можно изменить через API:

```
PUT /api/logistic-truck/:logistic_id/:truck_id
{
  "count": 100,  ← Количество километров
  "price": 0,
  "comment": ""
}
```

### При обновлении заявки:
```
PUT /api/logistics/:id
{
  "logistic_trucks": [
    {
      "truck_id": 1,
      "count_logistics": 150  ← Указываете километры
    }
  ]
}
```

## Проверка в Postman

1. **Создайте заявку с указанием километров:**
   ```
   PUT /api/logistic-truck/1/2
   {
     "count": 200,  ← 200 километров
     "price": 0,
     "comment": ""
   }
   ```

2. **Завершите заявку:**
   ```
   PUT /api/logistics/1/finalize
   ```

3. **Проверьте результат через 10 секунд:**
   ```
   GET /api/logistics/1
   ```
   
   В ответе `logistic_trucks[0].price` будет рассчитана на основе 200 км!

## Формула в коде (Django)

```python
# Базовая цена за километр
base_price_per_km = random.uniform(50.0, 150.0)

# Коэффициент
coefficient = random.uniform(0.8, 1.2)

# Расчет
calculated_price = count_logistics * base_price_per_km * coefficient

# Минимальная цена
min_price = 100.0
calculated_price = max(calculated_price, min_price)
```

## Важно

- Цена рассчитывается **асинхронно** (5-10 секунд)
- Расчет происходит **только при завершении заявки** модератором
- Если `count_logistics = 0` или не указано, будет ошибка
- Минимальная цена гарантирована (100 рублей)
