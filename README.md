# Лабораторная 4 – SPA Backend

## Цель
Завершение бэкенда для SPA: аутентификация, авторизация, Swagger.

## Проверка
- Аутентификация через Swagger, получение JWT/куки.  
- GET списка заявок: 401/403 для гостя, свои заявки для пользователя, все — для модератора.  
- PUT завершения заявки: только модератор может обновить.  
- Проверка сессий через Redis.

## Задание
- Реализовать методы аутентификации и регистрации.  
- Авторизация через сессии и куки, автозаполнение пользователя при создании заявки.  
- Описание методов в Swagger.  
- Проверка прав: без авторизации — только чтение, пользователь — свои методы, модератор — все методы.

## Sequence диаграмма
Основные HTTP-запросы: аутентификация, услуги, корзина, черновая заявка, формирование заявки, завершение модератором. Использовать домены как Lifeline и передавать ключевые данные через arguments.
