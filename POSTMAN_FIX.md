# Исправление проблемы с Postman

## Проблема
Вы получаете HTML страницу Adminer вместо JSON ответа от API.

## Причина
Вы обращаетесь к неправильному порту:
- ❌ **8081** - это Adminer (веб-интерфейс для БД)
- ✅ **8080** - это Go API сервер

## Решение

### 1. Проверьте, что Go сервер запущен

```bash
# Запустите Go сервер
cd /Users/ermmakoov/Documents/RIP
go run cmd/RIP/main.go
```

Должны увидеть сообщение:
```
Server start up
```

### 2. Используйте правильный URL в Postman

**Правильный базовый URL:**
```
http://localhost:8080
```

**Примеры правильных запросов:**

1. **Регистрация:**
   ```
   POST http://localhost:8080/api/users/register
   ```

2. **Вход:**
   ```
   POST http://localhost:8080/api/users/login
   ```

3. **Получить грузовики:**
   ```
   GET http://localhost:8080/api/trucks
   ```

4. **Получить черновик:**
   ```
   GET http://localhost:8080/api/logistic/draft
   ```

5. **Добавить грузовик:**
   ```
   POST http://localhost:8080/api/logistics/draft/add/1
   ```

6. **Завершить заявку (модератор):**
   ```
   PUT http://localhost:8080/api/logistics/1/finalize
   ```

### 3. Настройка Postman

1. Создайте новую коллекцию или используйте существующую
2. Создайте переменную окружения:
   - **Variable**: `base_url`
   - **Initial Value**: `http://localhost:8080`
   - **Current Value**: `http://localhost:8080`

3. Используйте переменную в запросах:
   ```
   {{base_url}}/api/users/register
   ```

### 4. Проверка работы сервера

Проверьте, что сервер отвечает:
```bash
curl http://localhost:8080/api/trucks
```

Должен вернуться JSON, а не HTML.

## Порты в системе

| Порт | Сервис | Назначение |
|------|--------|------------|
| 8080 | Go API | Основной API сервер |
| 8081 | Adminer | Веб-интерфейс для БД (не для API!) |
| 8001 | Django | Асинхронный сервис расчета |
| 5433 | PostgreSQL | База данных |
| 6379 | Redis | Кэш и сессии |

## Быстрая проверка

1. Откройте браузер и перейдите на:
   ```
   http://localhost:8080/api/trucks
   ```
   
   Должен вернуться JSON с грузовиками.

2. Если видите HTML или ошибку - Go сервер не запущен или работает на другом порту.

## Если проблема сохраняется

1. Проверьте, что Go сервер запущен:
   ```bash
   lsof -i :8080
   ```
   
2. Проверьте логи Go сервера на ошибки

3. Убедитесь, что используете `http://localhost:8080`, а не `http://localhost:8081`
